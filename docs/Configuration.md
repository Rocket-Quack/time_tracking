# Configuration

## Time Tracking Settings
Core configuration includes:
- Booking increment (minutes)
- Day label format in weekly booking
- Billing rate basis
- Overtime calculation settings
- Vacation settings and balances
- Holiday list usage and validation
- Reminder notifications for missing bookings

## Holidays
Holiday lists can be enabled to:
- Block booking on holidays
- Include holidays in forecasts and monthly totals

## Booking rules
- Group project booking can be enabled when teams need to book directly on parent projects.

## Vacation and sickness
Vacation and sickness projects can be configured to track balances and adjust overtime.
